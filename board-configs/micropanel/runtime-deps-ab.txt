# --- A/B additions -----------------------------------------------------------
# overlayroot: the read-only root the A/B engine requires. It is an
# initramfs-tools hook, and this board's custom kernel boots without an
# initramfs today - the appliance hook builds one. Declared here so the
# build-dep purge cascade cannot take it.
overlayroot
# The update path on the device: xz decompresses the slot image, curl fetches
# a release, openssl verifies the manifest signature (raw ed25519 against the
# key pinned in the image), and ca-certificates lets curl authenticate an
# https release server. The signature check needs no certificates, which is
# why a device with no clock and no network can still install from USB.
xz-utils
curl
openssl
ca-certificates
# Present via the base, declared anyway: the engine's slot write and the
# factory reset use them (lsblk/findmnt, e2label/e2fsck, the vfat boot slots).
util-linux
e2fsprogs
dosfstools
