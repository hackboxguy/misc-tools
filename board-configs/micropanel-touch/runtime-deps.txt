# Stage 4 update path: curl fetches the release, openssl verifies the manifest
# signature, and ca-certificates lets the fetch authenticate an HTTPS release
# server. The signature check itself needs none of these certificates - it is
# raw ed25519 against a key pinned in the image - which is why a device with no
# clock and no network can still install a signed release from USB.
curl
openssl
ca-certificates
# Network diagnostics (base-features slice 3e). iperf3 is the throughput test
# itself; avahi-utils is how a client finds a server without anyone typing an
# address - the panel publishes _iperf3._tcp while its server runs and browses
# for the same service as a client, which is what the OLED build does and the
# single most useful thing about the feature in a room full of sockets.
iperf3
avahi-utils
