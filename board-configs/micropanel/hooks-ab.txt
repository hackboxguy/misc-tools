# micropanel: hook list for the A/B (--layout=ab) image.
#
# hooks.txt followed by the appliance conversion, which must run last: it
# turns the authored image into a read-only-root appliance (overlayroot +
# initramfs for the custom kernel, /data persistence, service changes, the image
# manifest). board.conf selects this list through HOOK_LIST_ab, so the
# single-slot image's hook list does not change. tests/test_ab_layout_static.sh
# fails if the lines above the appliance hook stop matching hooks.txt.
#
# Format: HOOK_SCRIPT[|GIT_REPO|GIT_TAG|INSTALL_DEST|DEP_LIST|POST_CMDS|CMAKE_ARGS]
# ${VAR} references are expanded from the environment when the list is loaded;
# ${REPOBINS} points at the directory holding local binary repos (sp6bins,
# archsp6, ...) and is exported by build-image.sh (workspace sources dir).
#
# A hook that clones a repo MUST carry that repo in its GIT_REPO field, even
# when the hook does the cloning itself and ignores the field otherwise. The
# apps stamp is built from the GIT_REPO fields on these lines (build-image.sh
# apps_stamp_inputs -> git_remote_rev), so a bare line means pushes to the repo
# it builds do not invalidate the stamp: the apps stage is skipped and the
# image silently keeps the old code.
